# Nova Roadmap

Features deliberately excluded from v0.1, in rough priority order.

## v0.2 — Data

- Lists: `[1, 2, 3]`, indexing, `push`, `join`, `repeat for each`
- `length` extended to work on lists

## v0.3 — Modules and safety

- `import` and multi-file programs
- `try` / `catch` for recoverable errors
- Assertions: `expect x > 0`

## v0.4 — Expressive

- String interpolation: `"Hello, {name}"`
- Default parameters and variadic functions
- Closures and higher-order functions
- Ternary expression: `x if cond otherwise y`

## v1.0 — Production

- A bytecode compiler (for speed)
- A standard library of modules
- A package manager
- An online playground
